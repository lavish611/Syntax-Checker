# 🔍 Syntax Checker

A web-based syntax checking tool designed to help users identify and validate syntax errors in source code.

## 🚀 Features

- Check source code for syntax errors
- Simple and user-friendly interface
- Instant validation
- Clean and responsive design
- Helps users identify coding mistakes quickly

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- C++
